## 3. Ciblage : où trouver les bars

**Villes prioritaires** (fort volume + budget accessible) :
Lyon, Lille, Bordeaux, Toulouse, Montpellier, Nantes, Strasbourg,
Rennes, Marseille, Nice.

**Segments à contacter en premier** :
1. Bars à quiz / blind test existants (connaissent le format).
2. Bars à cocktails / speakeasy (clientèle qui aime l'animation).
3. Bars étudiants près des universités.
4. Bars de jeux (ludothèques, bars à board games).

**Où les trouver** :
- **Instagram** : recherche "bar quiz [ville]", "blind test [ville]",
  "bar à thème", regarde les stories/DM.
- **Google Maps** : bars avec "quiz", "blind test", "karaoké",
  "animation" dans les avis → site web → email.
- **Facebook** : groupes "animateur de soirée [ville]",
  "organisateur événement [ville]".
- **TikTok** : bars qui postent des vidéos de quiz → DM.

**Volume** : viser 30 contacts qualifiés/semaine. Taux de réponse
réaliste 10-20 %, soit 3-6 démos/semaine → 1-2 conversions/mois.

## 4. Concepts TikTok / Shorts filmables en 1 journée

1. **"Le blind test impossible"** : on joue un extrait ultra
   connu (Air Horn de la finale), tout le monde se trompe.
   Screen recording + réactions incrédules.
2. **"Devine la suite en 3 notes"** : clip de 2 s d'une intro
   culte, suspense, révélation à la fin. Le jeu en overlay.
3. **"J'ai fait un blind test dans mon bar"** : POV bar, QR code
   scanné par les clients, scoreboard qui grimpe. Preuve sociale.
4. **"L'épreuve chantée de [saison]"** : calé sur la room
   saisonnière (Noël en décembre, Halloween en octobre) : le
   meilleur format récurrent.

**Règle** : 1 vidéo/semaine, 20-40 s, son + suspense + réaction.
Lien en bio vers /bars ou la room du moment.

## 4bis. Visuels à joindre aux messages / pitch

Captures d'écran réelles de l'application (dossier `docs/assets/`).
Les joindre systématiquement : un bar ou un organisateur comprend
le produit en 5 secondes avec une image, vs 5 minutes de lecture.

| Fichier | Contenu | Usage |
|---|---|---|
| `bars_landing.png` | Page `/bars` : hero + promesse + QR | DM/Instagram, à mettre en pièce jointe ou en capture d'écran du site |
| `room_live_tv.png` | **Mode TV** : scoreboard, « Scanne pour buzzer ! » + QR code | LE visuel à montrer : c'est l'écran qui tourne chez le bar |
| `room_lobby.png` | Vue joueur : chat, playlist, classement, « Lancer la party » | Pour montrer ce que voient les clients sur leur téléphone |

**Conseil** : pour les bars, envoyer `room_live_tv.png` en premier
(c'est ce qu'ils verront sur leur écran), puis `bars_landing.png`
pour les détails. `room_lobby.png` en complément si on parle de
l'expérience client.

> Note : la vue TV s'affiche sur `/rooms/{id}/live` (id numérique,
> ex. la room démo publique `demo`). Le QR code affiché pointe vers
> la room : en production il affiche le vrai domaine, pas localhost.
