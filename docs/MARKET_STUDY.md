# Étude de marché, Blind'All Music (France)

Données chiffrées sourcées pour la stratégie GTM. Sources en fin de
document. Chiffres arrondis, ordre de grandeur assumé.

## 1. Marché du jeu vidéo en France

Source : SELL (Syndicat des Éditeurs) / Médiamétrie, bilan 2025.

| Indicateur | Valeur |
|---|---|
| Chiffre d'affaires | 5,8 Mds € (+2,9 %) |
| Joueurs (10 ans et +) | 40,2 millions (~73 % de la population) |
| Jouent au moins 1x/semaine | 76 % des joueurs |
| Âge moyen | 40 ans (parité quasi parfaite H/F : 51/49) |
| 18+ | 88 % des joueurs (35,4 M d'individus) |
| Écosystème mobile | 1,8 Md € (+11 %, record historique) |
| Temps de jeu moyen | 6h25/semaine |

Lecture : le jeu vidéo est le **premier loisir culturel de France**,
devant le livre, le cinéma et la musique. Le public n'est pas « jeune
geek » : c'est Monsieur et Madame Tout-le-Monde de 40 ans. Un jeu
musical multijoueur dans le navigateur touche exactement ce public.

## 2. Marché musical en France

Source : SNEP, bilan 2025.

| Indicateur | Valeur |
|---|---|
| Chiffre d'affaires musique enregistrée | 1,071 Md € (+3,9 %) |
| Streaming audio+vidéo | 702 M€ (78 % du numérique) |
| Abonnements streaming payants | 553 M€ (+5,9 %) |
| Utilisateurs d'offres streaming | 18,7 M (pénétration 27,1 %) |
| Streams audio | 122 Mds (80 % via abonnements) |

Lecture : la pénétration streaming (27 %) est **inférieure aux grands
marchés mondiaux** : le réservoir d'utilisateurs musicaux payants
n'est pas saturé. Deezer (siège français, 9,1 M d'abonnés monde)
confirme que la musique est un réflexe d'abonnement français.
Un blind test musical monétise directement cette culture.

## 3. Marché des bars en France (cible Pro)

Sources : INSEE, EPSIMAS, Costats (NAF 56.30Z / 56.30Y).

| Indicateur | Valeur |
|---|---|
| Établissements débit de boissons | ~44 800 (2025) / ~35 100 unités légales (INSEE 2023) |
| Chiffre d'affaires secteur | ~4,5 Mds € (2024) |
| CA médian par établissement | ~215 k€/an |
| Sans salarié | 61 % des établissements |
| Indépendants | ~95 % |
| Tendance | solde net négatif ~500 fermetures/an |

Lecture : marché fragmenté, majoritairement de très petites
structures. Ce sont des commerçants indépendants qui **décident
seuls** de leurs animations : cycle de vente court, pas de comité.
En contrepartie, ils sont sensibles au prix et ont peu de budget
marketing : l'offre doit être simple et le ROI évident.

## 4. Ce que coûte une animation blind test en bar (donnée clé)

Prestataires français relevés (tarifs publics 2025-2026) :

| Prestataire | Formule | Prix |
|---|---|---|
| QuizMania | Blind test original / thématique | dès 350 €, 790-890 € TTC |
| L'Heure Bleue | Blind test original | dès 350 €, 790 € TTC |
| MyAnimation (Nord) | Blind test essentiel 1h30 | 299 € TTC |
| PeachProduction | Blind test 30 min-2h | dès 299 € HT |
| Danomic (Valence) | Forfait 19h-1h | 300-350 € HT |
| Formules premium (DJ, karaoké, live) | | jusqu'à ~990 € TTC |

**Une soirée blind test animée coûte 300-900 € TTC.**
Blind'All Pro à 29 €/mois (ou 19 € promo) revient à **3-10 % d'une
seule soirée animée**, illimité. C'est l'argument de vente le plus
puissant du produit : pas « un abonnement de plus » mais « une
animation à 1/10e du prix, tous les soirs ».

Attention inverse : ces prestations vendent aussi **l'animateur et
le spectacle** (MC, karaoké, buzzers, sono). Blind'All ne remplace
pas l'ambiance humaine, il la complète ou la remplace les soirs
creux. Le positionnement doit jouer là-dessus : « animez vos soirs
creux sans animateur » plutôt que « remplacez votre animateur ».

## 5. Dépense des Français en abonnements numériques

Sources : Que Choisir (Observatoire conso 2025), Sharesub × IPSOS
(2026), CCM Benchmark / NPA (via franceinfo).

| Indicateur | Valeur |
|---|---|
| Abonnements facultatifs totaux | ~156 €/mois (sous-estimé, réel ~130-190 €) |
| Abonnements loisirs numériques | ~54 €/mois estimés |
| Mobinautes ayant déjà payé une app | 32 % (≈ 8 M de personnes) |
| Dépense moyenne apps/mois | ~3-5 € |
| Ont oublié de résilier un abonnement | 44 % |
| Ne font le point qu'1x/an ou moins | 50 % |

Lecture : le Français paie déjà ~150 €/mois d'abonnements et le
sous-estime massivement. 4,99 €/mois pour Plus est **sous le seuil
de douleur** : moins qu'un abonnement musical (10-11 €) et dans la
fourchette « app payante » (3-5 €/mois). Le churn est le vrai risque
(les gens oublient de résilier = aussi des revenus dormants, mais
le produit doit mériter sa place dans les 10 apps utilisées
régulièrement, règle observée : 3mobinautes/4 n'utilisent que ~10
apps/semaine).

## 6. TikTok France (canal acquisition)

Sources : TikTok newsroom, Le Figaro, Médiamétrie.

| Indicateur | Valeur |
|---|---|
| Utilisateurs mensuels France | 27,8 M (1er pays Europe) |
| Part des 18-29 ans utilisateurs | 48 % |
| Part des moins de 24 ans | 72 % |
| Temps moyen | ~95 min/jour |

Lecture : la France est le **premier marché TikTok d'Europe**.
L'audience est jeune mais le jeu cible aussi les 30-50 ans joueurs
de quiz : le format « réaction de groupe » transcende les âges.
Le contenu blind test musical est un format natif (son + suspense
+ compétition), pas besoin d'effets spéciaux.

### 7.2 Enseignements concurrents

- **Mukiz prouve le marché** : 1M+ downloads, top 3 App Store
  Musique France, monétisation par abonnement qui a justifié un
  accompagnement CRO dédié (firstapp.fr). Le blind test musical
  est un marché réel en France.
- **Mukiz a retiré le plan mensuel** et ne garde qu'annuel +
  hebdomadaire après tests A/B. Contre-donnée à notre choix
  « mensuel d'abord » : leur contexte (app mobile, forte base
  installée) diffère du nôtre (web/PWA, besoin de valider la
  rétention), mais à surveiller : si la rétention mensuelle est
  faible, envisager annuel plus tôt que prévu.
- **Personne ne fait le « bar digital » sérieusement** : les apps
  concurrentes sont des jeux entre amis à distance ou en petit
  groupe. Le mode TV + QR code + branding établissement (Pro)
  est un positionnement quasi vierge : c'est le différenciateur
  B2B et le canal d'acquisition.
- **Aucun acteur ne combine** : rooms persistantes publiques +
  daily + mini-jeux + duels async + saisonnalité + PWA + mode TV.
  La profondeur produit est réelle, mais Mukiz a les moyens.

## 8. TAM / SAM / SOM (ordres de grandeur)

**B2B bars (Pro)** :
- TAM : ~44 800 débits de boissons, dont une fraction « anime ses
  soirées » (estimons 10-20 % = 4 500-9 000 établissements
  adressables, plutôt bars de jeu/à thème/étudiants que cafés).
- SAM réaliste année 1 : 50-200 bars (1-4 % des adressables).
- SOM prudent : 5-30 bars = **145-870 €/mois MRR** à 29 €.
- À 500 bars (2,5 % des adressables) : ~14,5 k€/mois, déjà
  significatif pour un projet indie.

**B2C (Plus)** :
- TAM : 40 M de joueurs FR, dont amateurs de quiz/musique
  (Mukiz à 1M downloads en est la preuve d'adresse ; prenons
  1-5 % de joueurs = 400 k-2 M d'adressables).
- SAM : les FR qui jouent à des jeux musicaux multijoueurs en
  ligne, disons 100 k-500 k personnes.
- SOM : 2 % de conversion free→payant sur une base de
  10 k-50 k utilisateurs = **200-1 000 abonnés = 1 000-5 000
  €/mois**.

**Hypothèse combinée réaliste à 12 mois** :
5-15 bars Pro (145-435 €) + 200-800 Plus (1 000-4 000 €) =
**~1 000-4 500 €/mois MRR**. Fourchette basse = projet viable
côté coûts ; fourchette haute = revenus significatifs pour une
seule personne.

## 9. Implications stratégiques

1. **Le B2B bar est le meilleur couple ROI/effort** : marché
   fragmenté de décideurs uniques, prix de référence hostile
   (300-900 €/soirée), argument « 1/10e du prix » imparable,
   et chaque bar acquis amène 20-50 joueurs (acquisition B2C
   gratuite). Viser 5-15 bars en priorité absolue.
2. **Le B2C se joue sur la rétention et le bouche-à-oreille** :
   face à Mukiz (1M downloads, budget), on ne gagne pas par les
   features mais par la communauté FR, la saisonnalité et le
   mode « entre potes / au bar ». TikTok + rooms publiques.
3. **4,99 €/mois est bien positionné** pour la France (sous le
   seuil des 5 €, dans la fourchette app payante). Le risque
   n'est pas le prix mais la valeur perçue : le daily + perks
   doivent créer l'habitude quotidienne.
4. **Le churn est l'ennemi n°1** : 44 % des Français ont déjà
   oublié de résilier un abo. Le produit doit donner une raison
   de revenir CHAQUE jour (daily, rooms, saisons). Le dashboard
   admin (rétention à surveiller via metric_snapshots) devient
   l'outil de pilotage.
5. **Fenêtre TikTok** : la France est le 1er marché TikTok
   Europe, le format blind test est natif. C'est le canal
   d'acquisition B2C à plus fort levier pour un coût nul.
6. **Différenciation à assumer** : ne pas copier Mukiz (course
   aux fonctionnalités perdues d'avance). Assumer « le blind
   test qui remplit votre bar » (B2B) + « le blind test entre
   potes, gratuit et sans pub si tu soutiens » (B2C).
